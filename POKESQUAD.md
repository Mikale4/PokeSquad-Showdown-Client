# PokeSquad Battler's Showdown site

A fork of [Pokémon Showdown's client](https://github.com/smogon/pokemon-showdown-client) (AGPL-3.0, so this fork is public
and open source too; based on its commit `ab4b77b`) for **PokeSquad Battler**
([Mikale4/PokeSquadBattler](https://github.com/Mikale4/PokeSquadBattler)). It connects to PokeSquad's Showdown server
([Mikale4/PokeSquad-Showdown](https://github.com/Mikale4/PokeSquad-Showdown)), whose **[Gen 9] PokeSquad** format plays the
game's own battles.

- `play.pokemonshowdown.com/pokesquad.html`: the home page. Its settings point at PokeSquad's server
  (`pokesquad-showdown.onrender.com`; `?~~host:port` tries another) and say it has no login server (`noguestsecurity`).
- No login server: **Choose name** sends the name straight to the server (`client-main.ts`), and on connecting the name you
  chose last time comes back by itself (`panel-mainmenu.tsx`).
- `.github/workflows/pokesquad-pages.yml`: builds the client and publishes it on GitHub Pages.

Sprites, sounds and the Pokédex data still load from Pokémon Showdown's own site.

## The teambuilder on PokeSquad's data

- `play.pokemonshowdown.com/pokesquad/data.js` is generated by the game's build (`tools/build_showdown_data.js` and
  `tools/showdown_data_loader.js` in Mikale4/PokeSquadBattler; never edit it). Once Showdown's data has loaded it lays the
  game's over it as the mod `gen9pokesquad`: the Pokémon the game has, what each learns, each move's slot, numbers and text,
  each Pokémon's Abilities, the held items, and the Sketch, Copycat and Mirror Move copies for S1 and S3.
- `battle-dex-data.ts`: a format with `pokesquad` in its id is `isPokeSquad` and uses that mod (`battle.ts` too, for tooltips).
- `battle-dex-search.ts`: the `pokesquad` format type: the game's Pokémon, learnsets with nothing borrowed from a
  pre-evolution, Abilities and held items; moves listed by slot (`pokeSquadMoves`), only the edited slot's when a slot's
  box is open (`moveSlot`).
- `battle-team-editor.tsx`: three move boxes, S1, S2 and S3; a move always goes to its own slot's box (`moveSlotOf`,
  `slotMoves`); stats at the game's IVs with no EVs (only the nature to choose); no Tera; level fixed at 100.
- `battle-searchresults.tsx`: a move's slot in place of its PP.
- The turn meter: the server's `|custom|-pokesquadmeter|actor|ident=meter;...|next;...` lines (`battle.ts`: `turnMeter`,
  `pokesquadActor`, `pokesquadOrder`) drawn as a bar under each HP bar and the turn order in the right sidebar
  (`battle-animations.ts`: `updateTurnOrder`; `style/battle.css`: `.psmeter`, `.psorder`), and in the tooltip. `pokesquad.html` loads
  this build's `js/battle-animations.js` and `js/battle-animations-moves.js` instead of `data/graphics.js` (which only a full
  build makes, so the page used to fall back to Showdown's own copy).
- One format: the Battle! box starts on the server's first format when it has no Random Battle (`panel-mainmenu.tsx`), a new
  team is a [Gen 9] PokeSquad team (`panel-teambuilder.tsx`), and the format menu opens a lone section and drops the
  generation buttons when the server has one generation (`panel-teamdropdown.tsx`).
